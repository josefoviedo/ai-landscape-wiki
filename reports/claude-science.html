01

TL;DR

Claude Science, launched in beta on June 30, 2026, is Anthropic's science workbench: one environment where a researcher can read the literature, query 60+ scientific databases, write and run the analysis code, drive a cluster, and produce figures — without bouncing between tools. The single most important thing to understand is that it is not a biology model. It runs the same Claude models everyone else gets and wins on workflow: it orchestrates specialist models like Boltz-2, Evo 2, and OpenFold3 through NVIDIA BioNeMo rather than competing with them. Its signature claim is provenance — every figure ships with the code, environment, and message history that made it — and a reviewer agent checks citations and calculations as it works. Early users report order-of-magnitude speedups; the standing caveat is that a general model orchestrating specialist tools inherits both their errors and its own tendency to miss domain nuance. It carries no separate price, but heavy compute bills to your own HPC or Modal account.
02

What it is

New to computational biology tooling? Start here (skippable)

A computational biology result is rarely one program. A typical question — "does this variant change how the protein binds?" — touches a sequence database, a structure predictor, a statistics environment, and a compute cluster, each with its own file formats and access rituals. The friction is not any single step; it is the seams between them, and the fact that six months later nobody can reconstruct exactly which version of which script made figure 3. Claude Science is an attempt to put all of those steps in one conversation that remembers what it did.

FactAnthropic frames Claude Science as bringing "fragmented tools into a single research environment where scientists can conduct all stages of their work" — literature analysis, multi-step execution, figure and manuscript generation, and refinement. It runs where the researcher already works: locally on macOS or Linux, or on a remote machine over SSH or an HPC login node, so large or sensitive datasets need not leave the systems they already live on; only the context each step needs is sent to Claude.

ReadingThe strategic shape is familiar: this is the same move Anthropic made with Claude Code, aimed at a different profession. Rather than shipping a better protein model, it is trying to own the operating layer where scientific work actually happens — a bet on workflow rather than on a new model, as TechCrunch put it at launch.

03

Product & technology

The mental model first: a generalist coordinating agent that can hire specialists, call real scientific tools, and submit real compute jobs — then check its own work.

You talk to one coordinating agent. It has access to 60+ curated skills and connectors and can spin up sub-agents for specialist tasks. A request in plain language becomes a plan, then code, then — if the job is heavy — a submitted cluster job, then a figure with its provenance attached. 

You:  "Does the R273H variant change predicted binding for these 40 ligands?"
      → agent drafts a plan, asks before reaching new resources
      → pulls structures (PDB) + variant annotation (ClinVar)
      → calls Boltz-2 via BioNeMo for affinity prediction
      → submits the sweep to your HPC over SSH
      → returns a figure + the exact code and environment that made it

Reproducible, richly rendered artifacts

FactClaude Science renders scientific objects natively — 3D protein structures, genome-browser tracks, chemical structures — and emits figures alongside the code that created them: the exact code and environment, a plain-language description of how it was made, and the full message history. Figures can be edited in plain language ("log scale that axis") and the agent rewrites its own code. A separate reviewer agent inspects outputs for wrong citations, untraceable numbers, and figures that disagree with their code. Beta users asked for a "replication" button to re-check results skeptically; adding it measurably improved accuracy.

Compute management

FactFor heavy work the agent drafts a plan, asks before reaching new resources, then writes and submits jobs to your own HPC cluster over SSH or to a Modal account for on-demand GPUs, scaling "from a single GPU to hundreds as needed." Because the session holds context in memory, large datasets load once, and a session can be forked to compare two approaches without losing the original thread.

What it runs on

FactIt uses the same Claude models available to everyone — including Claude Opus 4.8 — with no special access or gating. Domain power comes from the surrounding scaffolding, not a private model: 60+ databases, plus NVIDIA's BioNeMo Agent Toolkit, which connects it natively to BioNeMo's life-science models including Evo 2, Boltz-2, and OpenFold3. Labs can save their own pipelines as reusable skills that later sessions inherit.

04

Market position

Claude Science sits one layer above most of its category siblings. Several of them are dependencies, not rivals.

AlphaFold, Boltz, RFdiffusion (Baker Lab), EvolutionaryScale's ESM3, AlphaGenome, and Arc Institute's Evo 2 are specialized predictive or generative models — they fold proteins, design binders, read genomes. Claude Science does none of that itself. It decides which model to run, prepares the data, executes the code, and interprets the result. Through BioNeMo it literally invokes Evo 2, Boltz-2, and OpenFold3 — so NVIDIA BioNeMo is both sibling and substrate.

Risks & limitations

Where this is genuinely weak, assumed, or unresolved — not a caveat ritual.

  • Hallucination is not solved, and Anthropic says so. It frames creativity and hallucination as related products of probabilistic reasoning, unlikely to disappear entirely. The reviewer agent reduces the rate; it does not make outputs trustworthy by default.
  • The reviewer checks form, not biology. It validates citations, calculations, and figure↔code agreement — none of which catches a scientifically wrong-but-internally-consistent result.
  • Orchestration inherits its models' errors. Predictions come from Evo 2, Boltz-2, OpenFold3 and friends. If a specialist model is systematically wrong for your ligand class, Claude Science will confidently carry that error downstream.
  • Reproducibility ≠ correctness. Provenance makes a result auditable, which is genuinely valuable and genuinely not the same as right — as the UCSF group implied by independently validating their output.
  • Domain nuance in regulated work. Scientists at launch warned a general model can miss nuance in regulatory guidance or assay design; pharma buyers want measurable error rates, validation protocols, and defined human decision rights before trusting it in a submission path.
  • Beta, platform, and cost edges. Beta software; macOS/Linux only (no Windows); Team/Enterprise needs admin enablement; serious compute bills to your own budget, so the marginal cost of a sloppy sweep is real.
  • Governance is unsettled. If this becomes an operating layer for research, the institutions defining evidence, licensing, and integrity standards around it matter as much as the software — and they do not exist yet.
Bottom line for a genomics or bioinformatics lab: adopt it as the coordinating layer that drives AlphaFold-class tools, not as a replacement for them, and treat its outputs as fast, auditable drafts that still need your validation step. The failure mode to guard against is not obvious nonsense — it is a well-formatted, fully reproducible, confidently wrong figure.
